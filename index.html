How to get a HAR file

  1. Open Chrome DevTools with F12 and go to the Network tab. Tick Preserve log.
  2. Clear the log, then visit the pages you want to study.
  3. Right click in the request list and choose Save all as HAR.
  4. Drop the file here. Repeat with a second browsing profile to compare.

Third party domains per page

A third party is any website domain other than the one you visited, for example doubleclick.net on a news site. The big number is the average count per page.
